## Engineering Standards Wrapper

When generating tasks:

- Keep tasks grouped by independently testable user story.
- Include exact file paths once they are known.
- Add validation, contract/parity, docs/runbook, and release evidence tasks
  where applicable.
- Do not create tasks that depend on unavailable CI or release infrastructure.
- Include a task to update the owning issue or handoff notes with verification
  evidence when the work completes.
