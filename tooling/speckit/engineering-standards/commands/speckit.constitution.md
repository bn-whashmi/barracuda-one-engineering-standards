## Engineering Standards Wrapper

Before applying the upstream constitution workflow, ensure the constitution
captures these standing principles when relevant:

- Issue-first traceability for meaningful changes.
- Explicit repository validation model.
- Secure handling of sensitive data and privileged behavior.
- Cross-surface parity for multi-client work.
- Release evidence for production-facing releases.

When updating the constitution, do not hard-code a CI provider or require pull
requests unless the repository explicitly chooses that governance model.
