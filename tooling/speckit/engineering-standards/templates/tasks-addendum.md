## Engineering Standards Task Requirements

Include tasks for the following when applicable:

- Link or update the owning issue with spec, plan, and task artifact paths.
- Add or update contract, parity, or fixture evidence for changed interfaces.
- Add focused tests for each independently testable user story.
- Run the repo's documented release gate or record why it cannot run.
- Record production release evidence after production-facing changes ship.
- Update docs, runbooks, or environment examples when behavior or operations
  change.

Tasks MUST keep the Spec Kit checkbox format and include concrete file paths
once implementation paths are known.
