## Engineering Standards Checklist

- [ ] Specs avoid implementation details and sensitive data.
- [ ] Plans identify validation, release, rollback, and observability needs.
- [ ] Tasks are grouped by independently testable user story.
- [ ] Cross-surface behavior has parity evidence.
- [ ] Contract changes include contract or fixture verification.
- [ ] Production-facing changes include release evidence.
- [ ] Skipped checks are documented with a concrete reason.
