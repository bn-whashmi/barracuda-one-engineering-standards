# QA Review

Review for:

- Changed behavior without tests.
- Missing unit tests.
- Missing regression tests.
- Edge cases and boundary conditions.
- Failure paths.
- Test assertions and test quality.
- Tests that merely increase coverage without validating behavior.
- Missing integration, contract, or UI testing when unit tests are insufficient.

QA review overlaps with engineering review. Do not duplicate an already clear
engineering finding unless QA provides additional test-specific evidence or a
different failure mode.
