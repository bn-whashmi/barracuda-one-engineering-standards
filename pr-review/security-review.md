# Security Review

Review for:

- Authentication and authorization.
- Tenant isolation.
- Injection and unsafe query construction.
- Data exposure and sensitive logging.
- Secret handling.
- Unsafe deserialization.
- Input validation.
- Dependency risk.
- Dangerous APIs.
- Destructive operations.
- TLS or other security-control bypasses.
- Privilege escalation.
- Cross-tenant access.
- Unauthenticated administrative endpoints.

Escalate high-risk changes to the appropriate human, domain owner, or security
reviewer when the repository's risk model requires it.
